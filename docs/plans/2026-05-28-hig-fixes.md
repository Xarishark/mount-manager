## Task 6: Keyboard Shortcuts + ShortcutsWindow

Addresses audit finding **M1** — the largest single fix on the branch.

**Approach:**

- Add a `Gio.SimpleAction` for each shortcut on the `Adw.Application` (`app.quit`, `app.shortcuts`) and on the `MainWindow` (`win.close`, `win.add-share`, `win.refresh`, `win.show-menu`).
- Use `Gtk.Application.set_accels_for_action()` to bind shortcuts.
- Build a `Gtk.ShortcutsWindow` programmatically (no UI file — the rest of this codebase doesn't use them).
- Add a "Keyboard Shortcuts" entry to the primary menu above "About".
- Rewire existing handlers (refresh, add-share, about) through the new actions so accelerators and menu items both flow through the same code path.

**Files:**
- Modify: `mount_manager_ui.py`
- Modify: `mount_manager.py` (only to install the `app.quit` accelerator on the `Adw.Application`)

- [ ] **Step 1: Add the `Adw.Application` accelerators and `app.quit` / `app.shortcuts` actions**

In `mount_manager_ui.py`, replace the entire `MountManagerApplication` class:


with:

```python
class MountManagerApplication(Adw.Application):
    def __init__(self) -> None:
        super().__init__(application_id=APP_ID, flags=Gio.ApplicationFlags.DEFAULT_FLAGS)

        quit_action = Gio.SimpleAction.new("quit", None)
        quit_action.connect("activate", lambda _a, _p: self.quit())
        self.add_action(quit_action)
        self.set_accels_for_action("app.quit", ["<Primary>q"])

        shortcuts_action = Gio.SimpleAction.new("shortcuts", None)
        shortcuts_action.connect("activate", lambda _a, _p: self._show_shortcuts())
        self.add_action(shortcuts_action)
        self.set_accels_for_action("app.shortcuts", ["<Primary>question"])

    def _show_shortcuts(self) -> None:
        window = self.props.active_window
        if window is None:
            return
        shortcuts_window = build_shortcuts_window(window)
        shortcuts_window.present()

    def do_activate(self) -> None:
        window = self.props.active_window
        if window is None:
            window = MainWindow(self)
        window.present()
```

- [ ] **Step 2: Add the `build_shortcuts_window` helper**

In `mount_manager_ui.py`, *inside* `run_gui()` and **above** the `class AddShareDialog` definition, add:

```python
def build_shortcuts_window(parent: Gtk.Window) -> Gtk.ShortcutsWindow:
    """Construct the keyboard shortcuts dialog for the app."""
    window = Gtk.ShortcutsWindow(transient_for=parent, modal=True)

    section = Gtk.ShortcutsSection(section_name="main", visible=True)

    general = Gtk.ShortcutsGroup(title="General")
    general.add_shortcut(
        Gtk.ShortcutsShortcut(title="Add Share", accelerator="<Primary>n")
    )
    general.add_shortcut(
        Gtk.ShortcutsShortcut(title="Refresh", accelerator="<Primary>r")
    )
    general.add_shortcut(
        Gtk.ShortcutsShortcut(title="Primary Menu", accelerator="F10")
    )
    general.add_shortcut(
        Gtk.ShortcutsShortcut(title="Keyboard Shortcuts", accelerator="<Primary>question")
    )
    general.add_shortcut(
        Gtk.ShortcutsShortcut(title="Close Window", accelerator="<Primary>w")
    )
    general.add_shortcut(
        Gtk.ShortcutsShortcut(title="Quit", accelerator="<Primary>q")
    )
    section.add_group(general)

    window.add_section(section)
    return window
```

Note: `Gtk.ShortcutsWindow` and its supporting classes (`ShortcutsSection`, `ShortcutsGroup`, `ShortcutsShortcut`) are part of GTK 4 and require no additional imports beyond `Gtk`, which is already imported.
